## Para 16 [12-15]
Mountainous UAV path planning usually requires trade-offs among reachability, safety constraints, path cost and dynamic disturbances, and existing studies have developed several technical routes. Graph search methods, represented by A*, D*, LPA* and D* Lite, usually discretize the environment into grids, nodes or graph structures and search for feasible paths under the guidance of edge costs [12-15]. These methods are interpretable, can express path costs and constraints, and are compatible with task terminals, edge-cost updates and heuristic search [15]. However, in complex three-dimensional environments, direct dense-grid or voxel representation rapidly increases the number of nodes and candidate edges, and replanning may repeatedly search many unaffected regions [16-18]. For mountainous scenes, the key issue in graph search is not only the search algorithm itself, but also how to construct a searchable graph that satisfies safety constraints without excessive expansion [7,16-17].

Sampling-based and intelligent optimization methods have also been widely used for UAV path planning. The result obtained by A* or LPA* search is a discrete waypoint sequence. However, real flight trajectories are usually smooth, so the discrete points generated by the algorithm need to be processed to improve trajectory continuity [46-47]. This processing does not change airway graph construction, edge-cost calculation or incremental replanning. It is used only to output the final flight trajectory.
